fix(i18n): translate four hints the coverage test could not see

A second audit, deliberately using different heuristics from the existing
guards, turned up English still reaching the screen in a Chinese panel:

- DesignModal   placeholder="e.g. Home Network, Rack Power"
- EdgeModal     placeholder="e.g. 20" and 'e.g. 1G, trunk...\nsecond line'
- RackCablePanel placeholder="e.g. Uplink to core"
- CableLayer    <title>{' (click to select, Delete to remove)'}</title>
- NodeModal     the "(defaults to node IP)" placeholder
- timeFormat    the whole relative-time formatter — "just now", "5m ago" …
                 the main app translates all of it, this copy did not

The blind spot was in isProse(), which required a leading capital. That is
what keeps Tailwind class strings out of the sweep, but it also waved through
every hint that opens lower-case, which is most of the form hints a user reads
while filling something in. The fix is a narrow second pass over hint
attributes only, not a loosened global rule — lowering the capital requirement
buried the signal in a few hundred className values.

Two scanner defects surfaced while wiring it up and are fixed here too: keys
are now unescaped, so the source spelling `a\nb` matches the runtime value
rather than reporting a translation that exists; and `??` joins the operators
that disqualify an operand, so `form.check_method ?? 'ping'` is no longer
collected as a key.

CHECK_TARGET_PLACEHOLDERS stays in English and is translated at the render
site — a module-level table would freeze the locale at import. Its one
copy-bearing value is registered in RENDER_SITE_TABLE_KEYS, and a new test
asserts it has an entry in the *merged* dictionary, since that is the one
place a reworded string could otherwise lose its translation silently.

Verified by reverting each fix and watching the guard fail: 2 of the 3
attribute-shaped hints go red. The third is a table lookup, guarded by the
RENDER_SITE_TABLE_KEYS test instead. The known limit is written down in the
test: a JSX child on the line after its element is not scanned.
